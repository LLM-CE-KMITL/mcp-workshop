# ADR-013: แอปเดโมแยกจาก UI ของผู้เรียน

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)

- **บริบท:** เดโมต้องปลอดภัยและอ่านง่ายต่อหน้าผู้ชม และต้องรันได้แม้ไม่มีอินเทอร์เน็ต
- **ตัดสินใจ:** [apps/demo-app/](../../apps/demo-app/) มี UI ของตัวเอง (starters เรียงตามสคริปต์เดโม, ตารางสถานะรวมช่วงข้อมูล) และโหมด `replay` เล่น trace ที่บันทึกไว้ (`make demo-record` หลังทุกครั้งที่ reseed) UI ของผู้เรียน ([apps/chainlit-ui/](../../apps/chainlit-ui/)) ใช้ starters และ health banner ชุดเดียวกับเดโม (`sys.path` ชี้ไป `demo-app`) เพื่อให้หน้าตาและพฤติกรรมตรงกัน
- **ผลที่ตามมา:** (+) เดโมไม่ล้มเมื่อเครือข่ายล่ม (−) trace ต้องบันทึกใหม่หลัง reseed Chainlit แสดง starters เฉพาะตอนแชทว่าง (ข้อความต้อนรับจะซ่อนปุ่ม จึงแสดง banner เป็นข้อความในแชท) และเก็บค่าตั้งจาก `.chainlit/` ของ cwd
