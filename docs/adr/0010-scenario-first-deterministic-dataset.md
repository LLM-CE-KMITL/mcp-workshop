# ADR-010: ชุดข้อมูลแบบ scenario-first และ seed แบบกำหนดผลได้

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)
- ADR ที่เกี่ยวข้อง: [ADR-009](0009-regex-grounding-instead-of-llm-judge.md)

- **บริบท:** ข้อมูลสุ่มไม่รับประกันว่ามีคำถามที่น่าสนใจ และวัด hallucination ไม่ได้ถ้าทุกคำถามมีคำตอบ
- **ตัดสินใจ:** เขียนเฉลย (Scenario Bible) ก่อน แล้วสร้างข้อมูลให้เฉลยเป็นจริง: ต้องมีคำถามที่ตอบแหล่งเดียวไม่ได้, คำถามที่คำตอบคือ "ไม่มีข้อมูล", เวลาเป็นแบบสัมพัทธ์ และทุกอุปกรณ์มีบทบาท ย่อส่วนเหลือ 10 อุปกรณ์/2 site/120 ticket/2,000 บรรทัด log/35 circuit ใช้ `SEED_RANDOM_SEED` ให้ได้ชุดเดียวกันทุกครั้ง ([data/scenarios.md](../../data/scenarios.md), [docker/seeder/](../../docker/seeder/))
- **ผลที่ตามมา:** (+) เทสต์และ eval อ้างอิงเฉลยเดียว (L6 วัดความกล้าตอบว่าไม่รู้) (−) แก้ seed ต้องแก้ scenarios.md ชุดคำถาม และเทสต์ให้ตรงกัน ค่าตายตัว เช่น `device_count` ใน resource ต้องแก้ตาม
