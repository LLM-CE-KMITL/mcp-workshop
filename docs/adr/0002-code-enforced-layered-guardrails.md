# ADR-002: Guardrail บังคับด้วยโค้ดหลายชั้น

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)
- ADR ที่เกี่ยวข้อง: [ADR-014](0014-redact-secrets-at-tool-output.md)

- **บริบท:** กฎที่เขียนใน prompt เป็นแค่คำขอ โมเดลหรือ prompt injection ฝ่าฝืนได้ ระบบนี้เข้าถึงข้อมูลลูกค้า
- **ตัดสินใจ:** วางเป็นชั้น: (1) role `mcp_reader` อ่านอย่างเดียวที่ระดับฐานข้อมูล (2) ตรวจรูปร่างคำสั่ง (3) จำกัดผลลัพธ์ (4) ปิดบังความลับ (5) audit log ถอดชั้นใดชั้นหนึ่งแล้วระบบต้องยังปลอดภัย ([guardrails.py](../../apps/mcp-server/security/guardrails.py))
- **ผลที่ตามมา:** (+) ความปลอดภัยไม่พึ่งพฤติกรรมโมเดล มี audit trail และเป็นโจทย์ Red-team (Challenge 5) (−) ชั้น (2) และ (3) ยังไม่ถูกต่อสายใน server ตอนนี้ (ดู[AGENTS.md หัวข้อ 7](../../AGENTS.md#7-ปัญหาและข้อสังเกตที่ทราบแล้ว) ข้อ 2) tool รับเฉพาะพารามิเตอร์ที่กำหนดไว้ ไม่รับ SQL ดิบ จึงลดความเสี่ยงได้อีกทาง
