# ADR-001: ReAct loop แทน planner/executor

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)
- ADR ที่เกี่ยวข้อง: [ADR-011](0011-tool-docstring-as-selection-contract.md)

- **บริบท:** แบบเดิมคือวางแผนทั้งชุดล่วงหน้า (`plan_created`) แล้วรันตามแผน ซึ่งพังเมื่อ step แรกให้ข้อมูลที่ทำให้แผนที่เหลือไม่ถูกต้อง (เช่นต้องรู้อุปกรณ์จาก ticket ก่อนจึงรู้ว่าจะหา upstream ของอะไร)
- **ตัดสินใจ:** ตัดสินใจทีละขั้น: ทุกรอบโมเดลเห็นคำถามและ observation ทั้งหมดแล้วเลือก tool ถัดไปหรือหยุด ผลของ step ก่อนหน้าเป็นเพียงข้อความในบทสนทนา ไม่มี dependency graph ชัดเจน ([react.py](../../apps/agent-api/agent/react.py))
- **ผลที่ตามมา:** (+) ปรับตัวตามหลักฐาน ไม่มี event วางแผน (−) ใช้ LLM หนึ่งครั้งต่อ step จึงช้ากว่าและแพงกว่า ต้องมี LoopGuard ป้องกันวนซ้ำ (หยุดเมื่อเกิน 8 step, เรียก tool เดิมเกิน 3 ครั้ง หรือเรียกซ้ำด้วยอาร์กิวเมนต์เดิม) Orchestrator-Workers ([orchestrator.py](../../apps/agent-api/agent/orchestrator.py)) เก็บไว้เป็นตัวเปรียบเทียบเท่านั้น
