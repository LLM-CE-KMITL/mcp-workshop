# ADR-014: ปิดบังความลับที่ขอบเขตขาออกของ tool

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)
- ADR ที่เกี่ยวข้อง: [ADR-002](0002-code-enforced-layered-guardrails.md)

- **บริบท:** config อุปกรณ์ที่เก็บใน PostgreSQL หรือ OpenSearch อาจมี community string หรือรหัสผ่านจริงปนอยู่ ถ้าเข้า context ของโมเดลก็หลุดต่อไปในคำตอบหรือ log ได้
- **ตัดสินใจ:** ผลลัพธ์ของทุก tool ผ่าน `redact_deep` ก่อนคืนออกไป (รวมข้อมูลที่อ่านจากฐานข้อมูล) ตรวจทั้งรูปแบบ `ชื่อ=ค่า` (ชื่อมีคำนำหน้าได้ เช่น `PG_PASSWORD`), `snmp-server community`, `authentication key`, สตริง base64 ยาว และ dict ที่ key ชื่อเหมือนความลับ
- **ผลที่ตามมา:** (+) ด่านสุดท้ายที่ไม่พึ่งว่าข้อมูลต้นทางสะอาด (−) ข้อความถูกเปลี่ยนรูป (เช่น `snmp-server community: [REDACTED] RO`) โค้ดที่ต้อง parse config ต่อจะเห็นรูปแบบใหม่ และอาจปิดมากเกินไปในบางกรณี (false positive)
