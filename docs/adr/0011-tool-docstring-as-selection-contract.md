# ADR-011: docstring ของ tool คือสัญญาการเลือก tool

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)
- ADR ที่เกี่ยวข้อง: [ADR-001](0001-react-loop-instead-of-planner-executor.md)

- **บริบท:** ReAct เลือก tool จากชื่อ คำอธิบาย และ schema ที่ส่งทุกรอบ ไม่มีกลไกอื่นบอกว่าควรใช้ tool ไหนเมื่อไร
- **ตัดสินใจ:** เขียน docstring ให้บอกทั้ง "ใช้เมื่อไร" และ "ห้ามใช้เมื่อไร" พร้อมชี้ tool ที่ถูกต้องกว่า (เช่น `search_tickets` ไม่ใช้ดูพฤติกรรมอุปกรณ์ปัจจุบัน ให้ใช้ `search_logs`) และสอดแทรกความรู้โดเมน (log บอกอาการ config บอกสาเหตุ)
- **ผลที่ตามมา:** (+) คุณภาพการเลือก tool มาจากข้อความ ไม่ต้องแก้โค้ดควบคุม (−) tool catalogue เป็นส่วนใหญ่ของ prompt ReAct (ราว 70%) ที่ส่งซ้ำทุกรอบ tool ที่ docstring สั้น (เช่น `get_upstream_devices`) จะถูกใช้ไม่ดี
