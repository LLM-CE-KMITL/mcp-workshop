# ADR-007: Intent Gate สองชั้น

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)
- ADR ที่เกี่ยวข้อง: [ADR-008](0008-topic-shift-memory-with-summaries.md)

- **บริบท:** การปล่อยให้โมเดลตอบทุกคำถามทำให้คำถามนอกเรื่องแตะฐานข้อมูล เปลืองโมเดลที่มีจำกัด และแยก "นอกขอบเขต" ออกจาก "ไม่ชัดเจน" ไม่ได้
- **ตัดสินใจ:** ชั้น 1 เป็น regex ตัดสินคำที่ชัดเจนโดยไม่เรียก LLM ชั้น 2 เป็น LLM จัดป้าย 4 แบบเมื่อกำกวม ป้ายที่ไม่ใช่ `in_scope` จบเทิร์นก่อนถึง tool ([intent.py](../../apps/agent-api/agent/intent.py)) คำถามที่อ้างบทสนทนาก่อนหน้าให้ถือเป็น `in_scope` และคำถามนอกขอบเขตไม่ทำให้หัวข้อใน memory เปลี่ยน
- **ผลที่ตามมา:** (+) 0 tool call สำหรับคำถามนอกเรื่อง ประหยัดทรัพยากร (−) fast path ที่ผิดแก้ยาก ต้องมีชุดทดสอบ ([tests/test_intent_gate.py](../../tests/test_intent_gate.py))
