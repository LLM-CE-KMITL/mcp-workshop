# ADR-008: Memory แบบตรวจการเปลี่ยนหัวข้อและสรุป

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)
- ADR ที่เกี่ยวข้อง: [ADR-007](0007-two-layer-intent-gate.md)

- **บริบท:** การต่อทุกเทิร์นเข้า context ทำให้ context ใหญ่และเจือจางจนโมเดลหลงรายละเอียดกลางบทสนทนา ทางแก้ไม่ใช่หน้าต่างที่ใหญ่ขึ้น
- **ตัดสินใจ:** ตรวจการเปลี่ยนหัวข้อด้วยความคล้ายของ embedding (เกณฑ์ 0.3) หรือวลีชัดเจน เมื่อเปลี่ยนจะสรุปหัวข้อเก่าเหลือบรรทัดเดียวเก็บเป็น archived summary (ส่งเสมอใน context) ส่วนบทสนทนาล่าสุดจำกัดที่ 6 เทิร์น ความจำระยะยาวเก็บใน pgvector ตารางแยก เพื่อไม่ถูกล้างตอน reset ข้อมูล workshop ([memory.py](../../apps/agent-api/agent/memory.py), [memory_longterm.py](../../apps/agent-api/agent/memory_longterm.py))
- **ผลที่ตามมา:** (+) context ลดชัดเจนหลังเปลี่ยนเรื่อง (ดู event `topic_changed`) และคำถามย้อนกลับตอบจากสรุปได้โดยไม่ต้องเรียก tool ซ้ำ (−) memory ระยะสั้นอยู่ใน RAM ต่อ process จึงหายเมื่อ restart
