# ADR-003: "ตอนนี้" มาจากข้อมูล และใช้ช่วงเวลาสัมพัทธ์เท่านั้น

- สถานะ: Accepted
- วันที่บันทึก: 2026-11-01 (บันทึกย้อนหลังจากโค้ดที่ใช้งานอยู่ ไม่ใช่เอกสารต้นฉบับของผู้ออกแบบ)
- ADR ที่เกี่ยวข้อง: [ADR-010](0010-scenario-first-deterministic-dataset.md)

- **บริบท:** โมเดลไม่รู้วันที่จริง ข้อมูลที่ seed ไว้ล่วงหน้าจะไม่มี log ในช่วง "24 ชั่วโมงที่ผ่านมา" ของวันเดโม และวันที่ที่โมเดลคำนวณเองมักผิดอย่างมั่นใจ
- **ตัดสินใจ:** `data_now` = timestamp ล่าสุดของ log (หรือ `DEMO_NOW`) เผยแพร่เป็น `clock://now` และ tool รับเฉพาะชื่อช่วง เช่น `last_7d` ที่แปลงด้วย `clock.resolve_range` ค่าที่ไม่รู้จักถูกปฏิเสธพร้อมข้อความสอนโมเดลแก้เอง ([clock.py](../../apps/mcp-server/clock.py))
- **ผลที่ตามมา:** (+) ข้อมูลไม่ขึ้นกับนาฬิกาเครื่อง ผล eval เทียบกันได้ (−) ถามช่วงที่เลื่อนออกไป เช่น "เมื่อสองสัปดาห์ก่อน" ได้ไม่แม่น ([AGENTS.md หัวข้อ 7](../../AGENTS.md#7-ปัญหาและข้อสังเกตที่ทราบแล้ว) ข้อ 5) ค่า "ตอนนี้" เปลี่ยนทุกครั้งที่ re-seed และถูก cache 5 นาที
