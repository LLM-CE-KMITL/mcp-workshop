# โจทย์ที่ N · ชื่อโจทย์

**เวลา HH:MM – HH:MM** (X นาที) · ตำแหน่งในตาราง

---

## เป้าหมายการเรียนรู้

อธิบายในหนึ่งย่อหน้าว่าโจทย์นี้ให้ประโยชน์ใดแก่ผู้เรียนที่การฟังบรรยายไม่สามารถให้ได้
พร้อมเชื่อมโยงกลับไปยัง Module ที่เกี่ยวข้อง

---

## สถานการณ์

ระบุบริบทเชิงงานจริง มิใช่โจทย์ที่ขาดบริบท
ควรเป็นสถานการณ์ที่มีโอกาสเกิดขึ้นจริงในงานดูแลโครงข่าย

---

## สิ่งที่ให้มา

- ไฟล์ / ข้อมูล / โค้ดตั้งต้น พร้อม path จริง
- ระบุให้ชัดเจนว่าสิ่งใดมีให้แล้ว และสิ่งใดต้องดำเนินการเอง

---

## เกณฑ์ผ่าน (Definition of Done)

- [ ] เกณฑ์ที่**วัดผลได้อย่างชัดเจน** ไม่กำกวม
- [ ] ควรเป็นตัวเลขหรือคำสั่งที่สามารถรันแล้วทราบผลได้ทันที
- [ ] หากมี test ให้ระบุคำสั่งที่ใช้
